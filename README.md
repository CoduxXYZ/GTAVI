# GTA VI Countdown

Access it [HERE](https://heisenbergx98.github.io/GTA-VI-Countdown/)

---

## Features
- Live countdown to GTA VI release (19 November 2026, midnight local time)
- Slow cinematic background slideshow with long crossfades
- Trailer links and pre-order buttons for PS5 and Xbox Series X|S
- Responsive design for all devices

## Development
```bash
npm install
npm run dev      # local dev server
npm run build    # type-check and build
npm run deploy   # publish dist/ to GitHub Pages
```
